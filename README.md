# Rewind11 Updater 🔄🕰️

**Windows Update — the way it used to look.**

Rewind11 Updater is a faithful **Windows 7-style Windows Update** for your Windows 11 machine. Launch it straight from the **Control Panel**, and it checks for the latest [Rewind11](https://github.com/WinAeroDev/Rewind11) updates, downloads them, and installs them automatically — all wrapped in that classic, nostalgic Windows Update interface you remember.

> Think of it as the companion that keeps your Rewind11 setup fresh, without you ever having to hunt down a new release.

---

## ✨ Features

- 🪟 **Authentic Windows 7 look and feel** — the classic Windows Update window, "Check for updates" button, progress bars, and all
- 🧭 **Launches from Control Panel** — opens right where the old Windows Update lived, so it feels native
- 🔍 **Automatic update checks** — scans for the newest Rewind11 releases with a single click
- ⬇️ **Auto-download** — grabs available updates in the background
- ⚙️ **Auto-install** — applies updates automatically, just like the real thing
- 📜 **Update history** — review what's been installed and when
- 🔔 **Update notifications** — get notified when a new Rewind11 version is available

---

## 📋 Requirements

- Windows 11 (25H2 Build 26200 or earlier)
- [Rewind11](https://github.com/WinAeroDev/Rewind11) installed
- Administrator privileges
- An internet connection

---

## 🚀 Installation

1. **Download** [`Rewind11Updater.zip`](https://github.com/WinAeroDev/Rewind11/raw/main/Rewind11Updater.zip) (or clone the repo — see below).
2. **Extract** the ZIP to a folder of your choice.
3. **Run the installer** (or `RUN_ME.cmd`) as administrator to register Rewind11 Updater in the Control Panel.
4. Open **Control Panel** and click **Windows Update** (now powered by Rewind11 Updater).
5. Hit **Check for updates** — the rest is automatic.

```bash
git clone https://github.com/WinAeroDev/Rewind11.git
cd Rewind11
```

---

## 🖱️ Usage

1. Open the **Control Panel**.
2. Select **Windows Update**.
3. Click **Check for updates**.
4. Rewind11 Updater will:
   - Look for the newest Rewind11 release
   - Download any available updates
   - Install them automatically
5. Sit back and enjoy the nostalgia while your Rewind11 setup stays up to date.

## ⚠️ Disclaimer

This tool integrates with the Control Panel and modifies system settings and UI components to replicate the Windows 7 Windows Update experience. While designed to be safe, **use at your own risk**. It's recommended to:
- Create a system restore point before installing
- Back up important data
- Review the script contents if you want full transparency
